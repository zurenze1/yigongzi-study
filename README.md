# 意公子内容策划与项目协作提案

祖仁泽的内容策划作品集案例，内容主体为意公子。包含创作者档案、受众快照、内容产品、创作方法及以2019至2020年8月公开项目为背景的当前协作提案。

本项目制作于2026年，工作项为当前提出的协作方式，不声明作者曾在意公子团队任职。拟定交付不作为实际拍摄、剪辑、发布或增长成绩。历史项目日期与本人贡献分别说明；两项2020节目只核条目日期与简介，未冒称完整听读。

网页保留已认可的首屏，加入自然枝叶开场与连续的水岸、书房、活动照片场景。档案分类、项目背景、方法与协作环节可切换，支持跳过、重播、暂停动态与减少动态。原作视频为意公子研究素材，支持静音播放、声音和进度控制。
